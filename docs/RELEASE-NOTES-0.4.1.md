# Waylaid Value 0.4.1 — candidate

Compare crate + filling-bundle costs per Merchant’s Favor, browse profession rewards and estimate exact unlock + crafting costs in WoW Forever.

Includes profession/level/class/skill filters, native item/effect tooltips, held-Favor and learned-recipe inputs, and a draggable minimap launcher.

Fixes minimap angles under Lua 5.1, incomplete profession detection, selected-recipe learned state, tooltip resets, large shopping quantities and invalid calculation inputs. Install ZIP includes the original-code license and third-party credits.

Automated checks pass, including 963 cross-language cost comparisons. This draft awaits actual-client rendering/interaction checks and screenshots. Live Auctionator and quest payouts remain unverified; catalogue unknowns stay explicit.

Install: quit WoW, extract WaylaidValue into _forever_/Interface/AddOns/, restart and type /crates. Keep SavedVariables when upgrading. Requires a configured supported price addon for estimates. Never install GitHub’s source archive as the addon.
