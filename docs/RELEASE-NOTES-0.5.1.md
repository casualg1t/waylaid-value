# Waylaid Value 0.5.1 — compact craft prices

Rewards now fits more items in the same list. Each compact row shows the item name, recipe Favor and one-craft material cost, so you can compare crafting costs without opening every item.

The Craft column excludes recipe unlocks and is per craft, not per output item. Held Favor and recipe ownership affect the selected unlock/total but not this material quote. Missing prices remain explicit; direct rewards show a dash. Role details stay in tooltips and the selected item panel.

Automated cost, callback and layout-bound checks pass. Native appearance remains to be checked in-game. Keep SavedVariables when replacing the addon folder.
